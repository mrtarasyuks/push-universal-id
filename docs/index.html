⚡ Push Universal ID

Хто ти на Push Chain?

Встав адресу з будь-якого чейна (Ethereum, Base, Arbitrum, BNB, Solana) — і побач її Universal Executor Account на Push Chain: чи задеплоєний, баланс, газ, історію транзакцій і застосунки, з якими він взаємодіяв. Нічого не підписуєш, гаманець не під'єднуєш — усе читається з публічного RPC та експлорера Donut-тестнету.

Read-only інструмент на публічних даних Push Chain (Donut testnet, chain id 42101). UEA обчислюється через офіційний @pushchain/core, активність — через Blockscout API. Зроблено однією людиною з допомогою AI. Код: GitHub.
